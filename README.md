# Sensei

A to-do app with a priority-ranked list and a Pomodoro-style focus timer. All state lives in the browser via localStorage.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` starts the dev server
- `npm run build` builds for production
- `npm run start` serves the production build
- `npm run lint` runs ESLint
